# 🛒 Sistema de Cadastro - Lojas Brincos e Companhia

Projeto desenvolvido como atividade prática para estudo de formulários HTML (método POST) e processamento de dados do lado do servidor utilizando PHP.

## 🚀 Tecnologias Utilizadas
- **HTML5:** Estruturação do formulário de cadastro.
- **PHP:** Recebimento, armazenamento em variáveis e exibição dinâmica dos dados.

## 📋 Funcionalidades
- Coleta de dados de novos colaboradores (Nome, Idade, Profissão, Salário e Experiência).
- Envio seguro via método `POST`.
- Apresentação formatada das informações linha por linha.
- Geração de mensagem de boas-vindas personalizada.
- Botão de navegação para retornar ao formulário.

## 📂 Arquivos do Projeto
- `cadastro.html`: Página do formulário de cadastro.
- `processaCadastro.php`: Script PHP responsável pelo processamento e exibição dos dados.
